## 💻 Running Projects Locally

Clone the repository:

```bash
git clone https://github.com/dhasarathi70/WEB-INTERFACE-PROJECTS.git
cd WEB-INTERFACE-PROJECTS
```

Then open the folder of the project you want to run.

| Project | Folder |
|---------|--------|
| Attendance Management | `attendance-management` |
| Calculator App | `Calculator_App` |
| Counter App | `Counter App` |
| Form Validation | `Form_Validation` |
| Hobby Gallery | `hobby-gallery` |
| Personal Portfolio | `portfolio` |
| Report Card | `Report-Card/my-react-app` |
| Student Profile Card | `Student Profile Card` |
| Student Academic Status | `student-academic-status` |
| TaskFlow Todo | `To-do app/my-react-app/taskflow-todo` |

### React projects

If the project folder contains a `package.json`, run:

```bash
npm install
npm run dev
```

Use the local URL shown in the terminal. If the project's `package.json` defines a different start script, use that instead (for example `npm start`).

### Static projects

If the project folder has no `package.json`, open its `index.html` file directly in a browser.
